For care groups, directors & procurement teams

One network standard across every home in your group.

Most care groups inherit networks of different ages, built by different contractors to different standards. We help bring them into line: one design, one approach to security and segmentation, and one team supporting the estate.

Discuss Your Care Home Portfolio

The problem with inherited networks

Every home different, and nobody with the full picture.

When each home has been networked separately, problems multiply quietly: different equipment, different settings, gaps in security and no consistent records. Rolling out care technology across the group becomes harder because every site behaves differently.

  • Equipment of different ages and makes from site to site
  • Security and segmentation set up differently, or not at all
  • No single view of how each home's network is performing
  • Documentation missing or in different formats
  • Each new care system needing its own workaround in each home

How we approach an estate

Survey, standardise, then roll out in phases.

  1. Survey the estate

    A consistent survey of each home, so sites can be compared like for like and prioritised by risk and need.

  2. Agree a standard

    One network design for the group: segmentation scheme, security rules, naming, equipment families where practical and documentation format.

  3. Plan the programme

    Upgrades phased across the estate to suit budgets, with the most urgent homes first.

  4. Deliver home by home

    Each home upgraded around its own routine and tested against the standard before moving on.

  5. Support consistently

    Monitoring, changes and support applied the same way in every home.

What a standard covers

The same answers in every building.

A group standard doesn't mean identical equipment everywhere. It means each home is designed, configured and documented to the same rules.

Design & security

  • A common segmentation scheme for care, staff, residents, guests and building systems
  • Consistent security rules between segments
  • A defined approach to internet resilience, with backup options assessed site by site

Operation & support

  • Network names and device configuration that staff recognise in every home
  • Documentation in one format, kept up to date
  • A repeatable way to add new care technology across the group
